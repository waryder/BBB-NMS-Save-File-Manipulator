Inventory Sorter

Since 0.5.0-alpha the Inventory Sorter button opens the Inventory Organizer dialog (window title Inventory Organizer). The older immediate-execution Sorter dialog was removed, so the Organizer is the only inventory sorting tool. See Inventory Organizer for every control.

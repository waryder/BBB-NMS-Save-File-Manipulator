Opening, saving, and protecting your data

  1. Open my existing NMS save and start editing.
  2. Find a save stored in a different folder or account.
  3. Understand which Auto or Manual save the app will load.
  4. Understand whether I’m editing my main game or expedition.
  5. Switch to another save without accidentally losing unsaved changes.
  6. Make a full backup before trying an edit.
  7. Save my changes back to the correct game file.
  8. Abandon unwanted edits and reload the saved data.
  9. Restore a full backup manually after an unsuccessful edit.

Working with Node View and Raw JSON

  1. Find the JSON that corresponds to something in the Node View.
  2. Find a particular name, item ID, or value in Raw JSON.
  3. Make a small JSON edit and update the Node View.
  4. Make densely formatted JSON easier to read.
  5. Copy a value or selected JSON text for use elsewhere.
  6. Export the loaded context’s JSON for inspection in another tool.
  7. Understand why the synchronization light and saved-data light disagree.

Working with bases

  1. Sort my bases by galaxy, system, and name.
  2. Keep my freighter base first when sorting.
  3. Arrange my bases in a custom order instead of the automatic sort order.
  4. Identify a base by its name, galaxy, system, and part count.
  5. Back up one particular base.
  6. Add a previously backed-up base to the loaded save.
  7. Copy a base record from one save into another using a base backup.
  8. Remove an unwanted base record.
  9. Remove several unwanted base records together.

Working with starships

  1. Upgrade one selected starship while leaving the others alone.
  2. Upgrade several starships in one operation.
  3. Understand what an upgrade will replace and what it will preserve.
  4. Understand how upgrading a Corvette differs from upgrading other ships.
  5. Interpret a result containing upgraded, unchanged, partially upgraded, and rejected ships.
  6. Distinguish an unoccupied ship slot from an unnamed ship.
  7. Remove an unwanted starship using the ship-specific deletion safeguards.
  8. Remove several unwanted starships without deleting my last occupied ship.

Working with inventories

  1. Gather resources from my carried inventories into one container.
  2. Give each item category its own destination container.
  3. Send several categories to the same destination.
  4. Organize only selected source inventories while leaving others untouched.
  5. Organize stationary storage instead of carried storage.
  6. Move selected categories while leaving other categories where they are.
  7. Use spare containers when the assigned destination fills up.
  8. Organize items without expanding any inventory’s capacity.
  9. Expand assigned destination inventories even when no items need moving.
  10. Review proposed inventory changes before applying them.
  11. Change my organization choices after reviewing, then generate a fresh review.
  12. Inventory Sorter and Inventory Organizer are now one tool.
  13. Route categories directly into selected inventories (legacy Sorter retired).
  14. Back up one inventory’s contents.
  15. Replace an inventory’s items from a backup and understand what else changes.
  16. Reuse my remembered inventory-organization settings.

Working with teleport endpoints

  1. Find and inspect a stored teleport endpoint.
  2. Set my saved player location to a selected endpoint.
  3. Understand what setting player location changes before saving it.

When something does not behave as expected

  1. A right-click command is missing—find the correct node to click.
  2. Highlight In Text Box refuses to navigate to my node.
  3. My JSON will not synchronize—locate and correct the editing error.
  4. Saving or another operation is blocked by unsynchronized text.
  5. A save slot is missing, unreadable, or cannot be loaded.
  6. An inventory destination fills up and some items stay behind.
  7. An operation reports completion, but I need to check what actually changed.
  8. Recover safely after an error without overwriting the backup or save I need.

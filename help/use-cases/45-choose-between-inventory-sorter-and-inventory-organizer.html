Inventory Sorter and Inventory Organizer are now one tool.

Use case 45 · Working with inventories

Help Index → Working with inventories → Use case 45

Since 0.5.0-alpha there is only one inventory sorting tool. The Inventory Sorter button in Inventory Processing → Node View opens the Inventory Organizer dialog; the older immediate-execution Sorter was removed.

Steps

  1. Open Inventory Processing → Node View and click Inventory Sorter. (control reference)
  2. Choose sources, category destinations and options, click Review Moves, then Apply To App Data. Use cases 34–44 walk through each choice. (control reference)

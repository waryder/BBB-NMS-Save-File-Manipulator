Find a particular name, item ID, or value in Raw JSON.

Use case 11 · Working with Node View and Raw JSON

Help Index → Working with Node View and Raw JSON → Use case 11

Search Text finds a name, item ID or other text in the active tab’s Raw JSON. It searches the displayed editor text, including pending edits, rather than searching every tab or the complete game save at once.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Load the intended save and choose the tab whose data should contain the value.
  2. Use a distinctive name, key or item ID, and remember that the same text may occur in multiple records.

Steps

  1. Click in Raw JSON near where you want the search to begin. For a full forward pass, place the cursor at the beginning of that editor. (control reference)
  2. Right-click inside Raw JSON and choose Search Text. (control reference)
  3. Enter the name, key, ID or value in the Enter search term field. Use a non-empty term. (control reference)
  4. Click Search Forward to find the next occurrence after the current cursor, or Search Backward to look before it. Repeat the appropriate button to move between occurrences. (control reference)
  5. When End of Search reports No more occurrences found, acknowledge it, click Close in Search Dialog, reposition the editor cursor, then reopen Search Text and search again. There is no automatic wrap; close/reopen before repositioning. (control reference)
  6. Click Close when finished and inspect neighboring keys and the enclosing record to confirm the match’s meaning. (control reference)

Expected result

  1. A found occurrence becomes the text selection and scrolls into view.
  2. At the end of a search direction, the app reports no more occurrences and retains the prior cursor position.

What changes, and when to save

Searching changes only cursor, selection and scrolling. It writes no app data, preference, clipboard, backup or live save file.

Check the result

  1. Confirm both the matched text and the record containing it. A matching item ID alone does not identify its inventory or ownership.
  2. If nothing matches, check the tab, search term and cursor position before concluding the value is absent.

Important details and recovery

  1. This is text search, not a JSON-path query or a replacement command.
  2. A successful search does not synchronize pending edits. Typing into the selected match would edit the text.

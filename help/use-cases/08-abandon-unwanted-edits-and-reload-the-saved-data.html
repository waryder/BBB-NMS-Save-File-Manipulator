Abandon unwanted edits and reload the saved data.

Use case 8 · Opening, saving, and protecting your data

Help Index → Opening, saving, and protecting your data → Use case 8

Reload from live files when you want to discard unwanted editor changes that have not been saved. This replaces the entire workspace, not just the active tab. It cannot undo an edit already written to the game files.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Close No Man’s Sky. Decide which unsaved edits you are willing to lose, including changes in other tabs.
  2. Identify the original account folder and game slot. If any unsynchronized text must be kept for reference, copy it elsewhere before loading.

Steps

  1. Do not choose File > Save NMS Save File if the purpose is to abandon the current edits. (control reference)
  2. Choose File > Open NMS Save File and verify Save Path and Game Slot against the save you intend to reload. (control reference)
  3. Inspect the displayed metadata, then click Load Slot. Choose OK at the warning only when discarding all current loaded data is intended. (control reference)
  4. If equal embedded timestamps require a decision, choose OK to load Manual or Cancel to keep the existing workspace. There is no forced Auto choice. (control reference)
  5. Wait for loading to finish, then inspect the records that contained the unwanted changes. (control reference)

Expected result

  1. Successful loading replaces edited model data and pending Raw JSON text with the newly selected live context.
  2. The loader chooses the newer validated embedded metadata time again; reloading the same slot does not necessarily select the same sibling if its files changed externally.

What changes, and when to save

Reloading reads live files and changes app memory only. It makes no live-file rollback. A confirmed folder change separately writes the folder preference.

Check the result

  1. Confirm the unwanted unsaved values are absent and the expected saved content is present.
  2. Check the loaded-slot status and green saved-data baseline. If loading failed, read the error and assume no successful replacement occurred.

Important details and recovery

  1. If you already saved the unwanted edit, reloading may load that same edited data. Use a verified backup and manual recovery guidance instead.
  2. Loading a different slot by mistake is not an undo; verify folder, slot and recognizable content.

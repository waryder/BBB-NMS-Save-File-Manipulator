Restore a full backup manually after an unsuccessful edit.

Use case 9 · Opening, saving, and protecting your data

Help Index → Opening, saving, and protecting your data → Use case 9

Full Live Save Restore displays manual instructions; it does not restore files for you. An actual full restore deletes the current live NMS directory contents before copying a chosen backup into place. Treat it as a whole-tree recovery decision, not an undo for one tab or slot.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Keep No Man’s Sky closed throughout recovery.
  2. Locate a known-good, complete backup and preserve it. Protect the current live directory separately if it contains progress you may need.
  3. Do not proceed with destructive manual work unless you understand the exact source, destination and scope.

Steps

  1. Choose File > Full Live Save Restore. (control reference)
  2. Read the warning and the actual live directory and backup-root paths resolved by this running app. If the dialog cannot determine them, stop and correct the folder selection through File > Open NMS Save File first. (control reference)
  3. Identify the exact timestamped backup directory you intend to restore. The displayed example contains a placeholder for its name; it is not ready to run unchanged. (control reference)
  4. If needed, click Copy Text to preserve the complete guidance for careful review. Copying does not execute the example or restore anything. (control reference)
  5. Click Close. Perform any manual restoration separately only after checking the displayed paths and preserving necessary data; there is no execute or automatic restore control in this dialog. (control reference)
  6. After a separately completed manual restore, reopen the intended slot in the app and inspect recognizable records before considering another save. (control reference)

Expected result

  1. Opening or closing the dialog leaves editor data, backups and live files untouched.
  2. Copy Text places the complete displayed instructions on the clipboard only.

What changes, and when to save

The app performs no restore write. Any manual deletion and copying outside it changes live files and can remove all accounts and slots under the displayed NMS directory.

Check the result

  1. Do not interpret closing the dialog as restore completion.
  2. After manual work, verify the intended backup contents are in the correct live directory and a fresh load shows expected records. App loading is not game acceptance.

Important details and recovery

  1. The example deletes all live-directory contents, including subdirectories; a wrong path or backup can permanently lose progress.
  2. Do not save a stale editor workspace over restored files. Reload first.

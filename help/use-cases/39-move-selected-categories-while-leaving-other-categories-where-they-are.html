Move selected categories while leaving other categories where they are.

Use case 39 · Working with inventories

Help Index → Working with inventories → Use case 39

Move resources and trade goods without routing crafted products, technology, consumables or special items. Explicitly reset all category choices so remembered routes cannot widen the operation.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Load the intended save and confirm its active Main or Expedition context. Make a full backup before changing data.
  2. Only one tab can hold unsynced Raw JSON at a time: leaving a tab with a red sync light asks Sync, Abandon or Cancel. Sync and compare exact values. Invalid or refused text stops the sync with a message and keeps the light red; [] is applied on Bases, Starships and Teleport Endpoints and refused on Inventory by the count rule.
  3. Inventory Raw JSON can be synced or Pretty Printed if it keeps exactly the same inventories in the same order. Organizer and Replace Items from Backup remain the simpler tools for moves and replacement.

Steps

  1. Resolve each tab’s unsynced Raw JSON before leaving it: the app asks Sync, Abandon or Cancel. Sync and verify exact values. After a parse error or refusal the text stays and the light stays red; correct it and retry. Inventory Raw JSON must keep the same inventories in the same order. (control reference)
  2. If Inventory Organizer is not already open, choose Inventory Processing → Node View → Inventory Organizer before using the dialog controls below. (control reference)
  3. Click Clear, then check only Exosuit. Leave every other inventory unchecked under Gather from these sources. (control reference)
  4. Set Resources → Container 1 and Trade goods → Container 2. Set Crafted products, Technology, Consumables and Special items to Leave where they are. (control reference)
  5. Uncheck Overflow: if destination is full, overflow to other 'Container' type storages. Uncheck Expand all Destination storages to 120 cells. This avoids extra receiving containers and changes to valid-cell capacity. (control reference)
  6. Click Review Moves. Check the two receiving routes, then choose Apply To App Data if the candidate matches your intended scope. (control reference)

Expected result

  1. Substance and Trade records from Exosuit can move to the two assigned containers. Other known categories and unknown category records remain where they started.
  2. Whole records are transferred without altering Amount, merging stacks or splitting them. A full destination can retain matching records in Exosuit.

What changes, and when to save

Review Moves changes no inventory data. Apply To App Data publishes the reviewed candidate in memory, marks it modified and closes the dialog. File → Save is separate and writes the loaded save target. Organizer preferences persist even when Close cancels the proposal; neither a review nor preferences create a save backup. Before a live write, check that every intended edit is present.

Check the result

  1. Inspect Exosuit after applying, including categories deliberately left in place. Check Container 1 and Container 2 for the intended record types and unchanged stack amounts.

Important details and recovery

  1. Leave where they are disables routing for that category, but assigning any destination while expansion is on can expand it even without arrivals.
  2. The review is not an item-by-item audit. Retained-only rows may disappear after Review Moves; inspect actual contents before saving.
  3. Choosing the source itself as destination is also a no-move route and does not trigger overflow.

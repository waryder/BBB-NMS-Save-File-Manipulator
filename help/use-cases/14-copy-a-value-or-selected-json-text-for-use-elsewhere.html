Copy a value or selected JSON text for use elsewhere.

Use case 14 · Working with Node View and Raw JSON

Help Index → Working with Node View and Raw JSON → Use case 14

Copy selected Raw JSON text when you need a value or snippet in another tool. If you use Copy This Node’s Text instead, you get the visible first-column node label, which may contain descriptive text rather than the underlying JSON value or object.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Open the intended loaded save and tab.
  2. Decide whether you need a displayed label, an unquoted value, or a valid JSON fragment. These are different clipboard contents.

Steps

  1. For underlying JSON, locate the field in Raw JSON with Highlight In Text Box or Search Text, then inspect the surrounding keys. (control reference)
  2. Select exactly the desired characters in Raw JSON. Include quotes, braces or brackets only when the destination needs that JSON syntax. A highlighted line may contain more than the value you need. (control reference)
  3. Right-click inside the editor and choose Copy from the standard text menu, or use Ctrl+C while the editor has focus. Do not choose Cut if you only want a copy. (control reference)
  4. For the displayed node label instead, right-click the intended Node View item and choose Copy This Node's Text. This is not a subtree export. (control reference)
  5. Paste into a separate scratch document or inspection tool and check the result before using it elsewhere. (control reference)

Expected result

  1. Copy places the selected editor characters on the clipboard without removing them.
  2. Copy This Node’s Text places the clicked item’s visible first-column text on the clipboard, not serialized child nodes.

What changes, and when to save

Copy replaces clipboard contents only. Selection and navigation do not change app data or live files. Pasting into another tool may have separate effects controlled by that tool.

Check the result

  1. Check the pasted content for unwanted labels, surrounding punctuation or missing JSON syntax.
  2. If you need the entire loaded context instead of one selection, use the Tools export command rather than assuming a node copy contains it.

Important details and recovery

  1. Do not paste sensitive save content into a public service without reviewing it.
  2. Pasting back into Raw JSON edits the workspace and requires deliberate synchronization; copying out does not provide an automatic import workflow.

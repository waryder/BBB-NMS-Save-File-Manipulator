Export the loaded context’s JSON for inspection in another tool.

Use case 15 · Working with Node View and Raw JSON

Help Index → Working with Node View and Raw JSON → Use case 15

Tools > Export 'BaseContext' JSON to Clipboard copies the whole loaded context model for inspection elsewhere. The menu label is fixed: if the loaded save selected ExpeditionContext, the exported model is that expedition context, not the inactive Main context.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Load the intended live save and verify its slot and recognizable data. Otherwise you may export startup or other current model data instead.
  2. Decide whether pending Raw JSON edits belong in the export. This command does not automatically synchronize them.
  3. Only one tab can hold unsynced Raw JSON at a time: when you leave a tab whose sync light is red, the app asks Sync, Abandon or Cancel. Resolve that tab before structured operations, which refuse while any tab is unsynced.

Steps

  1. Keep a copy of complex edits you cannot afford to retype. Invalid or refused text is never applied: the error is shown, the text stays and the light stays red. Inventory Raw JSON must keep the same inventories in the same order.
  2. To include pending edits in the export, sync that tab first and verify the values. Inspect actual values before exporting; otherwise export contains only the current model, not unsynced text. (control reference)
  3. Choose Tools > Export 'BaseContext' JSON to Clipboard. (control reference)
  4. Acknowledge the Copied notice, then paste into a separate JSON-capable inspection tool or plain-text document. (control reference)
  5. Inspect recognizable records and the top-level context contents. The export contains the loaded context, not the full outer save with both context branches. (control reference)
  6. If you save the pasted text elsewhere, use a separate inspection file. Do not overwrite a live game data or metadata file with this plain JSON. (control reference)

Expected result

  1. Clipboard text is an indented serialization of the current whole-context model, including its sections beyond the currently visible tab.
  2. Unsynchronized text is not included merely because it is visible in an editor. Export reads the model without performing a synchronization step.

What changes, and when to save

The export action replaces clipboard text only. It does not write a file, create a full backup, change preferences, or save live game data. Any earlier synchronization updates app memory separately. Compare the intended values before authorizing a live write.

Check the result

  1. Check expected records and any deliberately synchronized edits in the pasted result.
  2. Do not treat the Copied notice as a game-save or backup completion notice. Modified Data Saved is not cleared by exporting.

Important details and recovery

  1. This is not the compressed game-save format or a full-live-tree backup.
  2. There is no visible corresponding whole-context clipboard import command in the current UI.
  3. JSON inspection does not validate edited data against game behavior.
  4. Inventory Raw JSON sync and Pretty Print replace each inventory’s contents in place. Keep exactly the same inventories in the same order; a changed count, an empty entry or [] is refused without changing data. Inspect actual Name and Slots before saving.

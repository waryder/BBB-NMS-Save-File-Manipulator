Sort my bases by galaxy, system, and name.

Use case 17 · Working with bases

Help Index → Working with bases → Use case 17

Use the Bases tab’s automatic sort to group base records by their saved galaxy and system before ordering their names. This changes the underlying list order, not just the way labels are displayed.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Load the intended save and check whether its active context is Main or Expedition.
  2. Keep a full backup before changing the persistent base list.
  3. Only one tab can hold unsynced Raw JSON at a time: when you leave a tab whose sync light is red, the app asks Sync, Abandon or Cancel. Resolve that tab before structured operations, which refuse while any tab is unsynced.

Steps

  1. Keep a copy of complex edits you cannot afford to retype. Invalid or refused text is never applied: the error is shown, the text stays and the light stays red. Inventory Raw JSON must keep the same inventories in the same order.
  2. Open Bases. If Raw JSON has pending edits, use Sync to Node View before sorting so the operation uses the intended records. (control reference)
  3. Clear Move Freighter to Top on Sort if you want every record to follow the same galaxy, system, name ordering. (control reference)
  4. Click Sort By Gal, Sys, Name and acknowledge Bases Sorted when the refresh completes. (control reference)
  5. Review the reordered top-level base labels and their new list positions before saving. (control reference)

Expected result

  1. Records are ordered by numeric galaxy, numeric system, then the saved Name value. A missing address sorts using zero; a missing or empty name uses an empty string.
  2. Sorting does not move a base to another galaxy or rewrite its address.

What changes, and when to save

Changes stay in the loaded app data until File > Save NMS Save File writes the retained live slot and Main or Expedition context. Close No Man’s Sky and confirm that destination before saving; a green synchronization light alone does not mean the game file was saved. Compare the intended values before authorizing a live write.

Check the result

  1. Compare several adjacent galaxy/system groups, then compare names within one group.
  2. Check that the base count and individual part counts remain the same.

Important details and recovery

  1. With the freighter option checked, the first empty-name record is moved ahead of the sorted list. Name sorting is not a natural-number or case-insensitive naming tool.

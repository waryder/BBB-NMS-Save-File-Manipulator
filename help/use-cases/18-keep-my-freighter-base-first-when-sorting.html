Keep my freighter base first when sorting.

Use case 18 · Working with bases

Help Index → Working with bases → Use case 18

Keep the app’s freighter-style unnamed record above the automatically sorted base list. The checkbox is an extra step applied after the ordinary galaxy, system, name sort; checking it alone does not reorder anything.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Open the correct save context in Bases and retain a full backup.
  2. Identify your freighter base rather than assuming every unnamed record is a freighter.
  3. Only one tab can hold unsynced Raw JSON at a time: when you leave a tab whose sync light is red, the app asks Sync, Abandon or Cancel. Resolve that tab before structured operations, which refuse while any tab is unsynced.

Steps

  1. Keep a copy of complex edits you cannot afford to retype. Invalid or refused text is never applied: the error is shown, the text stays and the light stays red. Inventory Raw JSON must keep the same inventories in the same order.
  2. Find the intended base label. An empty Name is displayed as Unnamed Freighter Base; inspect its record if more than one base has that label. (control reference)
  3. Synchronize any pending Bases Raw JSON changes with Sync to Node View. (control reference)
  4. Check Move Freighter to Top on Sort. This control is checked when the tab is initialized, but verify its current state. (control reference)
  5. Click Sort By Gal, Sys, Name, then inspect the first record after the success message. (control reference)

Expected result

  1. The list is sorted by galaxy, system, and name first. The first record encountered with an empty or missing Name is then removed from that position and inserted at position zero.
  2. Only one matching record is promoted; the operation does not detect a freighter by its base type. If no empty-name record exists, there is no promotion.

What changes, and when to save

Changes stay in the loaded app data until File > Save NMS Save File writes the retained live slot and Main or Expedition context. Close No Man’s Sky and confirm that destination before saving; a green synchronization light alone does not mean the game file was saved. Compare the intended values before authorizing a live write.

Check the result

  1. Confirm the promoted record is actually the intended freighter base.
  2. Confirm other records retain their sorted order and that the total base count is unchanged.

Important details and recovery

  1. An unnamed ground base can satisfy the same test. If the wrong record moves first, do not save on the assumption that the caption guarantees freighter identity.

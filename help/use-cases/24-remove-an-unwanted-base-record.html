Remove an unwanted base record.

Use case 24 · Working with bases

Help Index → Working with bases → Use case 24

Remove one unwanted base record from the loaded Bases list. Select the complete base rather than deleting one of its fields; the command acts on the node you actually right-click.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Keep a full backup; optionally export the individual base for later reinsertion.
  2. Load the correct context and synchronize pending text before working in Node View.
  3. Only one tab can hold unsynced Raw JSON at a time: when you leave a tab whose sync light is red, the app asks Sync, Abandon or Cancel. Resolve that tab before structured operations, which refuse while any tab is unsynced.

Steps

  1. Keep a copy of complex edits you cannot afford to retype. Invalid or refused text is never applied: the error is shown, the text stays and the light stays red. Inventory Raw JSON must keep the same inventories in the same order.
  2. Find the base using its name, galaxy, system and Parts label. Expand or highlight its JSON if the name is ambiguous. (control reference)
  3. Collapse its children and right-click the complete labeled base directly beneath the array root. (control reference)
  4. Choose Delete Node and review the Delete Nodes confirmation. Cancel if the selection is not the intended single base. (control reference)
  5. Confirm only when ready, then inspect the refreshed list and Raw JSON before saving. (control reference)

Expected result

  1. The chosen base node is removed from the list and the app refreshes its model and text. Later base positions shift and the base count decreases.
  2. The generic base deletion command does not perform ship-specific ownership, appearance or primary-ship cleanup.

What changes, and when to save

Changes stay in the loaded app data until File > Save NMS Save File writes the retained live slot and Main or Expedition context. Close No Man’s Sky and confirm that destination before saving; a green synchronization light alone does not mean the game file was saved. Compare the intended values before authorizing a live write.

Check the result

  1. Check that exactly the intended base disappeared and nearby same-name bases remain.
  2. Check the remaining base count and review the full-save backup path before committing the edit.

Important details and recovery

  1. Deleting a nested Name, Objects or address node can damage a surviving record instead of deleting the whole base. Do not remove a Corvette’s linked PlayerShipBase here as a substitute for ship deletion; use the ship-specific safeguard workflow.

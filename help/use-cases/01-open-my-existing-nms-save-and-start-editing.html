Open my existing NMS save and start editing.

Use case 1 · Opening, saving, and protecting your data

Help Index → Opening, saving, and protecting your data → Use case 1

Load an existing Steam or GOG game slot into the four editing tabs. Opening the slot reads game files and replaces the app’s current editing data; it does not save an edit back to the game.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Close No Man’s Sky before working with its saves.
  2. Preserve any current editor work you need before loading another slot. Keep an independent backup before making changes.

Steps

  1. Choose File > Open NMS Save File. (control reference)
  2. Check Save Path. It starts blank on first use or when the remembered directory is unavailable. Use Pick Folder... to choose the intended Steam or GOG account folder, then review the separate preference-write confirmation. A suggested folder is not automatically loaded or remembered. (control reference)
  3. Select the intended Game Slot and inspect Save Name, Description and Modified. The disabled Save File field is a display, not a file-selection control. (control reference)
  4. Click Load Slot. Accept the warning about replacing currently loaded data only when you are ready to discard it. (control reference)
  5. If Equal save timestamps appears, choose OK only to load Manual, or Cancel to leave the current workspace unchanged. Wait for loading to finish. (control reference)

Expected result

  1. The app populates Bases, Starships, Inventories and Teleport Endpoints from the selected save’s active context.
  2. A successful live load establishes the saved-data baseline and retains the exact source for later saving.

What changes, and when to save

Load Slot replaces app memory only. Choosing and confirming another folder writes a preference. Live save files remain unchanged until a separately confirmed File > Save NMS Save File.

Check the result

  1. Check the loaded-slot status and inspect a recognizable record before editing.
  2. Confirm Live Save Loaded and Modified Data Saved are green after a successful load.

Important details and recovery

  1. A readable slot label does not guarantee all files required for loading are valid. If loading fails, review the error rather than saving the previous workspace by mistake.

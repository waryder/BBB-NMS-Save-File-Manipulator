Make a full backup before trying an edit.

Use case 6 · Opening, saving, and protecting your data

Help Index → Opening, saving, and protecting your data → Use case 6

Full Live Save Backup creates a verified ordinary directory copy of the live NMS tree before you try an edit. It protects the files currently on disk, including other account folders under that NMS root; it is not a snapshot of the editor workspace.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Close No Man’s Sky and stop other tools from writing its files.
  2. Check the source folder through File > Open NMS Save File first. If necessary, use Pick Folder... and approve the folder-preference write. You do not have to load a slot to request a backup.

Steps

  1. Choose File > Full Live Save Backup. (control reference)
  2. Read the proposal’s complete source path. A selected Steam st_* or GOG DefaultUser account folder expands to its containing NMS directory, so the scope includes the other accounts there and is broader than one loaded slot. (control reference)
  3. Review the new destination path, proposed disk usage and remaining free space. Backups are timestamped directories under Backups\Full NMS Save Backups in the app’s BBB NMS SFM Data storage folder (chosen at first startup). (control reference)
  4. Choose Save only if the source and destination are correct. Choose Cancel to create no backup output. (control reference)
  5. Wait for Backup complete and verified. Record the exact resulting destination and preserve that directory before editing. (control reference)

Expected result

  1. The backup preserves the source’s relative files and directories without decoding or re-encoding saves. Each copied file is checked against the source.
  2. The loaded model, retained save target, unsaved edits and saved-data light are not changed by the backup.

What changes, and when to save

Save in this backup dialog writes a new backup directory only. It does not write editor changes into live saves, and it does not mark those changes saved.

Check the result

  1. Check the completion notice’s exact path; a proposal or progress message is not success.
  2. If an error reports an incomplete destination, do not treat that directory as a verified backup. Preserve earlier good backups.

Important details and recovery

  1. Do not save unwanted edits first just to make this backup; the operation intentionally copies the pre-existing on-disk state.
  2. Restore is manual and destructive, not the inverse of an automatic Restore button.

BBB NMS Save File Manipulator — Help

Copy a base record from one save into another using a base backup.

Use case 23 · Working with bases

Help Index → Working with bases → Use case 23

Use a single-base backup as the transfer artifact between two saves. This copies a record into the destination’s loaded data; it is not a validated cross-account base migration or a move that removes the source.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Know which source and destination slots and contexts you intend to use.
  2. Keep full backups, especially of the destination. Resolve any unrelated unsaved edits before changing saves.
  3. Only one tab can hold unsynced Raw JSON at a time: when you leave a tab whose sync light is red, the app asks Sync, Abandon or Cancel. Resolve that tab before structured operations, which refuse while any tab is unsynced.

Steps

  1. Keep a copy of complex edits you cannot afford to retype. Invalid or refused text is never applied: the error is shown, the text stays and the light stays red. Inventory Raw JSON must keep the same inventories in the same order.
  2. Load the source save, open Bases, identify the complete base record, and use its Backup a Base command to write a distinct .nms_base.json file. (control reference)
  3. Use the NMS open/load workflow to load the destination save. Review the active Main or Expedition context; opening another file is not itself a save of source-side edits. (control reference)
  4. In destination Bases, right-click the array root and choose Restore a Base. Select the file exported from the source. (control reference)
  5. Inspect the new first record, its Name, GalacticAddress and Objects, and check for an existing destination duplicate before considering a live write. (control reference)

Expected result

  1. The destination receives a copy at list position zero. The original source record and exported backup file are not removed by restore.
  2. Existing destination bases are retained, even if a name or address matches the inserted record.

What changes, and when to save

Export writes only the standalone base file. Restore changes only destination app memory. File > Save NMS Save File, with the game closed and the destination confirmation checked, is the separate operation that writes the destination live file. Compare the intended values before authorizing a live write.

Check the result

  1. Confirm the currently loaded slot is the destination before saving.
  2. Compare the imported label and part count with the source record and ensure unrelated destination bases remain present.

Important details and recovery

  1. The app does not reconcile account ownership, coordinates, permissions or other game relationships during this copy. Do not promise that an imported base will be usable, owned correctly or universally compatible in-game.

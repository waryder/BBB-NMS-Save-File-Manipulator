Use case 53 · When something does not behave as expected

Help Index → When something does not behave as expected → Use case 53

Node View menus depend on the tab, the clicked node’s structural level and whether you clicked or dragged. Locate the intended record instead of using a destructive command as a substitute.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Identify the operation you actually want and back up before any data-changing action.
  2. Expand the relevant tree enough to distinguish its outer array, complete records and nested child fields.
  3. Only one tab can hold unsynced Raw JSON at a time: leaving a tab with a red sync light asks Sync, Abandon or Cancel. Sync and compare exact values. Invalid or refused text stops the sync with a message and keeps the light red; [] is applied on Bases, Starships and Teleport Endpoints and refused on Inventory by the count rule.
  4. Inventory Raw JSON can be synced or Pretty Printed if it keeps exactly the same inventories in the same order. Organizer and Replace Items from Backup remain the simpler tools for moves and replacement.

Steps

  1. Resolve each tab’s unsynced Raw JSON before leaving it: the app asks Sync, Abandon or Cancel. Sync and verify exact values. After a parse error or refusal the text stays and the light stays red; correct it and retry. Inventory Raw JSON must keep the same inventories in the same order. (control reference)
  2. Use an ordinary right-click on an actual Node View node. Clicking empty space supplies no node menu; right-clicking Raw JSON opens the text editor’s different menu. (control reference)
  3. For Set Player Location to this Endpoint, open Teleport Endpoints and click a complete endpoint directly beneath the outer array. Its child coordinates and the array root do not receive that action. (control reference)
  4. For Restore a Base, click the outer base array. For Backup a Base, click the base record. For Backup this Inventory or Replace Items from Backup, click a complete inventory directly below the inventory array. (control reference)
  5. If you see Delete N Nodes, dismiss the menu and try a stationary right-click: right-button dragging opens a separate selection/deletion menu on every tab. Check which visible nodes were included before ever confirming deletion. (control reference)

Expected result

  1. The normal menu presents only actions applicable to the clicked tab and node. Toggle Expansion 2 Levels, Highlight In Text Box and Copy This Node’s Text are general node actions.
  2. Normal Delete Node appears on bases and starships, not ordinary inventory or endpoint menus. Generic right-drag deletion remains exposed on all four tabs.

What changes, and when to save

Opening or dismissing a menu does not save. A changing action can modify memory immediately; any live write remains a separately confirmed File → Save.

Check the result

  1. Reopen the menu on the intended complete record and read the exact command before activating it. For starship deletion, select whole occupied ownership-slot records, not individual fields or the list root.

Important details and recovery

  1. Do not delete child nodes to force another command to appear. Generic deletion is not a safe inventory-management or endpoint-inspection shortcut.
  2. A menu command’s presence is not proof that arbitrary hand-edited data is valid. Resolve uncertainty before acting.
